# Noor — The Holy Quran

A responsive Quran reading and recitation website with an emerald-and-gold theme.

## Features
- Responsive layout for mobile and desktop
- Browse and search all 114 Surahs
- Arabic Quran text fetched live from [AlQuran Cloud](https://alquran.cloud/api)
- Audio recitation choices and verse-level playback
- Adjustable Arabic text size and locally saved bookmarks
- Introductory Tajweed learning guide

## Run locally
Open `index.html` in a browser with an internet connection. Quran text and recitation audio are fetched from AlQuran Cloud, so those features require the service to be reachable.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for deployment. GitHub will show the published URL in Settings → Pages.

## Accuracy note
The site uses Arabic text supplied by the selected API edition. The Tajweed guide is introductory; the website does not claim complete, verse-by-verse Tajweed annotation. Verified Madinah Mushaf page mapping is not included in this first version. For precise recitation, learn with a qualified Quran teacher.
